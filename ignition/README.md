# IGNITION

Arquivos relacionados ao sistema que integra os dados industriais de chão de fábrica à gestão estratégica. 
Divididos em: 
1. Leitura das tags relacionadas as variáveis de processo.
2. Atualização do banco de dados externo.
3. Elaboração de relatórios visuais de indicador OEE através de gráficos de tendência, dashboard e relatório de dados brutos.
